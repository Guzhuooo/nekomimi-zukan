# 猫娘完全图鉴 · 第二版

一本正经地介绍猫娘（nekomimi）的单页小站：定义、常见品种、野生观测记录（22 张插画）与饲养须知。

纯手写 HTML / CSS / JS，无框架、无构建步骤。

## 本地预览

任意静态服务器指向本目录即可，比如：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 图片版权

所有插画来自 [nekos.best](https://nekos.best) 收录的画师作品，版权归原作者所有。
每张卡片和页脚都标注了画师链接，喜欢请去原作页面支持。请勿商用。

## 素材处理

原图 PNG 经压缩转为 900px 宽的 WebP（脚本见 `manifest_raw.json`，记录了每张图的画师与原始出处）。
